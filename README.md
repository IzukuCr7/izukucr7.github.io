# izukucr7.github.io

Link-in-bio page for @aka_zidanxbd (IzukuSensei).

Single self-contained `index.html` — styles, the pixel-art background, cover art and the audio are all embedded, so there is no build step and no other asset to upload.

The views stat is a real global total, read from and incremented through the public counters API at abacus.jasoncameron.dev (`izukucr7.github.io/visits`), one hit per browser session. If that service is unreachable the page falls back to a local count.
